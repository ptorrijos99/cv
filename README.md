# Pablo Torrijos Arenas - Academic CV

This repository hosts the personal academic website and CV of **Pablo Torrijos Arenas**, Researcher at the University of Castilla-La Mancha (UCLM).

🌐 **Live Website**: [https://pablotorrijos.es/](https://pablotorrijos.es/)

## 🛠️ Maintenance

To add a new publication:
1.  Add the entry to `publications.bib`.
2.  Add the abstract (if available) to `abstracts.json`.
3.  Run `python scripts/bib_to_json.py` to regenerate `publications.json`. This is done automatically when you push to GitHub.
